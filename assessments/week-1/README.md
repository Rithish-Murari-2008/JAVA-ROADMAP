# Week 1 Assessment — Java Fundamentals and Problem Solving

**Topics covered:** Days 1–6: Java setup, syntax, variables, operators, conditions, loops, methods, arrays, strings, basic problem solving, Big O, hash maps, two pointers, packages, and access modifiers.

1. What are the roles of the JDK, JVM, and JRE, and how are they related?
2. Write a Java program that reads two integers and prints their sum.
3. Write a program that swaps two values, then describe how your approach changes if a temporary variable is not allowed.
4. Write a program that checks whether an integer is even or odd.
5. Write a program that finds the largest of three numbers.
6. Write a grade calculator using conditions and clearly define the grade boundaries.
7. Write a program that checks whether a year is a leap year.
8. Print a multiplication table for a user-provided integer.
9. Write a program that checks whether a positive integer is prime.
10. Write a method that returns the factorial of a non-negative integer.
11. Write a method to reverse a string and another to test whether a string is a palindrome.
12. Given an integer array, find its minimum, maximum, and second-largest distinct value.
13. Count the frequency of each character in a string.
14. Given two strings, determine whether they are anagrams.
15. Find a missing number from a sequence with one missing value.
16. Explain the time complexity of a single loop over an array and of two nested loops over the same array.
17. Solve Two Sum using a HashMap and state its time and space complexity.
18. Given a string, find its first non-repeating character.
19. Check whether a string of brackets is balanced.
20. Explain the difference between private, protected, public, and package-private access.
21. What do static and final mean in Java, and when might you use each?
22. Create a small utility class in a package and demonstrate importing it from another class.
