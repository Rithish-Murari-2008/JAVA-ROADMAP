# Week 4 Assessment — DSA, JDBC, Spring Boot, REST

**Topics covered:** Days 22–27: coding challenges, SQL, JDBC, PreparedStatement, Maven, Spring Boot, dependency injection, REST, DTOs, validation, layered architecture, JPA, and persistence.

1. Solve an array problem that returns the second-largest distinct value.
2. Solve a string problem that checks whether two strings are anagrams.
3. Given a string, return the first non-repeating character.
4. Use a HashMap to count element frequencies in an integer array.
5. Use recursion to compute a result and explain the base case.
6. Design a stack-based solution to validate bracket matching.
7. For each of your solutions, state time complexity, space complexity, and relevant edge cases.
8. Write SQL statements to create an employee table and perform create, read, update, and delete operations.
9. What are Connection, PreparedStatement, and ResultSet used for in JDBC?
10. Why should user-provided values be passed through PreparedStatement parameters rather than concatenated into SQL?
11. What problem does Maven solve in a Java project?
12. Explain dependency injection and inversion of control in the context of Spring.
13. What is the purpose of a Spring Boot application entry point?
14. Design REST endpoints for creating, listing, updating, and deleting employees. Specify HTTP methods and expected status codes.
15. What is a DTO, and why might an API avoid exposing persistence entities directly?
16. How would you validate an incoming request and return useful error information?
17. Explain the responsibilities of controller, service, and repository layers.
18. What is the role of a JPA entity and a Spring Data repository?
19. Design a relationship between Employee and Department and explain the data model.
20. How would you test success, invalid input, missing resources, and database failures in an Employee API?
