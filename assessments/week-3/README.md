# Week 3 Assessment — Modern Java, Files, Concurrency

**Topics covered:** Days 15–20: generics, sorting, lambdas, functional interfaces, Streams, Optional, date/time, file I/O, serialization basics, and concurrency.

1. What problem do generics solve in Java?
2. Write a generic method specification that returns the last element of a non-empty list.
3. Compare Comparable and Comparator.
4. Describe how you would sort Employee records by name, salary, and joining date.
5. What is a functional interface?
6. Give a use case for Predicate, Function, Consumer, and Supplier.
7. Write a lambda expression that sorts strings by length.
8. Describe the differences between Stream filter, map, flatMap, sorted, distinct, collect, and reduce.
9. Given a list of employees, specify a Stream pipeline to select employees above a salary threshold and collect their names.
10. How would you group a list of records by department using Streams?
11. What is Optional intended to represent, and what are two mistakes to avoid when using it?
12. Which Java date/time types would you use to represent a calendar date, a timestamp, and an elapsed duration?
13. Calculate the period between two dates and describe how you would handle an end date before a start date.
14. Design a program that reads a CSV file and handles missing files and malformed rows.
15. Compare buffered text I/O with object serialization.
16. What is the difference between Thread, Runnable, Callable, and ExecutorService?
17. What is a race condition? Describe a scenario where two tasks update shared state.
18. What is synchronization intended to protect?
19. When might concurrent collections be useful?
20. Describe how you would test a concurrent task processor without relying on timing assumptions.
