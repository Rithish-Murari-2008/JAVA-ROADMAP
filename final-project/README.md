# Final Project Planning

The source bootcamp suggests choosing one of these backend project themes:

- Fleet Management API
- Employee Management API
- Inventory API

Pick one after learning the Spring Boot, REST API, validation, and persistence topics. Do not start with the entire stack on Day 1.

## Planning checklist

- [ ] Choose one project and define its purpose
- [ ] Identify entities and their fields
- [ ] Sketch the database schema and relationships
- [ ] List API endpoints and HTTP methods
- [ ] Decide request/response DTOs
- [ ] Define validation rules
- [ ] Decide how errors will be returned
- [ ] Implement controller, service, and repository layers
- [ ] Add persistence and test the endpoints
- [ ] Document setup and example requests
- [ ] Prepare a short demo
