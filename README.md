# Java Roadmap — Beginner to Backend Foundations ☕

A beginner-friendly, 30-day learning path based on the **30-Day Java Developer Bootcamp**. The plan starts with programming basics, builds object-oriented Java and core problem-solving skills, then introduces Collections, Streams, files, concurrency, JDBC, and Spring Boot.

This is a learning roadmap—not a claim that any topic has already been completed.

## How to use this repository

1. Follow the days in order. If a topic is difficult, spend another day practicing it.
2. Read the matching `day-XX/README.md` before coding.
3. Write your own source files and keep them in the matching day's `src/` folder.
4. Record tests or terminal output in that day's `test-output/` folder when useful. Never upload secrets or private data.
5. Use the assessments only after studying the matching topics. **The `assessments/` folder contains questions only—there are no solutions or answer keys in that folder.**
6. Commit your progress to GitHub with clear messages.

## 30-day map

| Days | Focus | Milestone |
|---|---|---|
| 1–7 | Java setup, syntax, conditions, loops, methods, arrays, strings, problem solving, packages | Week 1 assessment |
| 8–14 | OOP, encapsulation, inheritance, polymorphism, equality, exceptions, Collections | Console Library Management System |
| 15–21 | Generics, sorting, lambdas, Streams, Optional, date/time, file I/O, concurrency | Week 3 assessment |
| 22–30 | DSA practice, JDBC, Maven, Spring Boot, REST APIs, layered architecture, JPA, final project | Final assessment and demo |

## A beginner-friendly daily routine

The source bootcamp proposes a demanding day: 45 minutes of concepts, 90 minutes of coding, 45 minutes of exercises, 30 minutes of HackerRank/DSA, and 15 minutes of verification. As a beginner balancing college, treat those times as a reference rather than a reason to rush. Understanding one topic well is better than ticking a box without understanding it.

## Repository structure

- `day-01/` … `day-30/` — concepts, learning objectives, and practice tasks
- `assessments/week-1/` … `assessments/week-4/` — topic-aligned assessment questions only
- `assessments/final/` — final assessment questions only
- `final-project/` — plan and document your chosen backend project
- `resources.md` — official documentation links
- `progress-tracker.md` — check off topics as you learn them

## Ground rules

- Try a problem yourself before looking for help.
- Write down errors and what fixed them.
- For algorithm questions, record time and space complexity when relevant.
- Do not claim a task is complete unless you have practiced and verified it.
- Never commit passwords, tokens, database credentials, or `.env` files.

## Bootcamp submission checklist

For each day, aim to keep a GitHub commit, source code, relevant test output, completed exercises, and a short self-assessment. The level of documentation can be simple at first and improve over time.
