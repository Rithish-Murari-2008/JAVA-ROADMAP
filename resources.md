# Learning Resources

Use these references alongside the day folders. The bootcamp PDF provides the 30-day topic sequence; these official resources are supplementary documentation, not replacements for the daily tasks.

## Java and tools
- Java learning resources: https://dev.java/learn/
- Java API documentation: https://docs.oracle.com/en/java/
- JDK downloads: https://jdk.java.net/
- Eclipse IDE: https://www.eclipse.org/ide/
- IntelliJ IDEA: https://www.jetbrains.com/idea/

- Java tutorials (Oracle): https://docs.oracle.com/javase/tutorial/

- Date and Time API: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/time/package-summary.html

## Practice
- HackerRank Java domain: https://www.hackerrank.com/domains/java
- LeetCode: https://leetcode.com/

**Beginner tip:** Do not try to read all documentation at once. Open the resource relevant to the current day's topic, practice a small example, and write notes in your own words.
